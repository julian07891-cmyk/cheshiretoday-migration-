# Typography

This directory documents Cheshire Today typography and is reserved for future approved specimens and usage examples.

- **Playfair Display** is the editorial headline family.
- **Public Sans** is the body, label, interface and call-to-action family.

Use Playfair Display primarily at weight `700`. Use Public Sans at weights `400–700` according to hierarchy. Avoid substituting Montserrat or making Inter the brand interface family.

Do not store or redistribute font files here without a separate licensing review.
