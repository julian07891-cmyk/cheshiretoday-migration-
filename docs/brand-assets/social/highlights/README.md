# Cheshire Today Instagram Highlight covers

## Production masters

- Canvas: `1080 × 1080 px`.
- Circular-crop safe area: the central `560 × 560 px` square (`x=260–820`, `y=260–820`).
- Background: Cheshire Today royal blue `#1E3A8A`.
- Icon: warm paper `#F7F4EE`.
- Style: centred monoline category symbol with `32 px` strokes and rounded line ends and joins.
- The cover contains no text, gradient, shadow, category label or masthead.

The production set contains `news`, `money`, `property`, `ai-tech`, `food-drink`, `places`, `transport`, `newsletter` and `reels`. The original `news.svg` and `news.png` define the shared construction system and must not be altered when extending the set.

## Export rules

- Treat each SVG as the permanent vector master.
- Export each matching PNG at exactly `1080 × 1080 px` in RGB/RGBA PNG format.
- Preserve the exact two-colour palette; do not recolour, add effects or move the icon outside the safe area.
- Use the PNG for Instagram and retain the SVG for future lossless exports.
