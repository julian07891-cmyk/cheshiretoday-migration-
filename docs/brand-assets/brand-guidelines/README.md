# Brand guidelines

This directory contains the consolidated Cheshire Today Brand Guidelines and will hold approved release exports.

`BRAND_GUIDELINES.md` is the approved Version 1.0 Markdown source for logo use, colour, typography, editorial imagery, social templates, accessibility, social publishing and prohibited treatments. The production website remains the authoritative visual baseline, supported by the parent Brand Asset Library README.

Generate a PDF from the approved Markdown source only when one is required; do not maintain a competing source document.
