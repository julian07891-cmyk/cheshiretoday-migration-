# Colours

This directory documents the production Cheshire Today palette and is reserved for future machine-readable swatches or colour-reference assets.

The approved baseline is defined in the library-level `README.md`: royal blue for identity, emerald for editorial accents, red only for genuine breaking news, warm paper neutrals for editorial surfaces, and slate tones for text.

Do not create platform-specific replacement palettes or assign arbitrary colours to editorial categories. Any future swatch export must preserve the exact approved HEX values and use sRGB.
