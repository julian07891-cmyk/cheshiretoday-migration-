# Logos

This directory is reserved for approved Cheshire Today logo, wordmark and monogram masters and their production exports.

Use an SVG-first workflow. Keep every approved vector master with its matching PNG exports, preserve clear space and do not redraw or overwrite the existing website logo without separate approval.

Recommended future PNG export widths are `2048`, `1024`, `512` and `256 px`, plus any channel-specific size documented alongside the asset. Transparent exports should remain RGBA; solid-background exports should identify the background in the filename.

No new logo suite has been approved yet.
